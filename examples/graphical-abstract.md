# Example: Carbon Capture Graphical Abstract

**Goal:** Communicate the steps of a generic cyclic CO2-capture process without adding experimental claims.

## Copyable prompt

```text
Create a widescreen graphical abstract explaining a generic solid-sorbent
carbon capture cycle. Arrange four labeled stages from left to right:
CO2-containing feed gas; capture in a solid sorbent bed; sorbent regeneration
with an energy input; concentrated CO2 collection. Add a separate return arrow
from regenerated sorbent to the capture stage. Use a clean scientific style,
minimal English labels, and a plain background. Do not invent efficiency
values, specific material compositions, or experimental results.
```

## Review checklist

- Correct order and direction of gas and sorbent flows.
- Regeneration connects back to capture.
- Labels use terminology consistent with the source study.
- No unsupported claims, metrics, or chemical species appear.
