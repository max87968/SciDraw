# Example: Biological Signaling Pathway

**Goal:** Create a reviewable figure from a researcher-specified sequence of pathway steps.

## Copyable prompt

```text
Draft a scientific pathway diagram for the following user-supplied conceptual
sequence: extracellular ligand binds membrane receptor; receptor activation
initiates an intracellular signaling cascade; a transcription factor moves
into the nucleus; gene expression changes. Draw four clearly separated stages
with directional arrows and short English labels. Mark the diagram
"conceptual illustration". Do not name specific proteins or add feedback
loops unless those details are provided in the source material.
```

## Review checklist

- Distinguish a generic illustration from a specific biological claim.
- Confirm arrow direction and localization (membrane, cytoplasm, nucleus).
- Add actual pathway names and mechanistic evidence only from verified sources.
- Check all labels and diagram relationships manually.

**Tool:** https://scidraw.org/tools/biological-pathway-generator

This example deliberately avoids asserting that a particular real-world pathway behaves in this exact way.
